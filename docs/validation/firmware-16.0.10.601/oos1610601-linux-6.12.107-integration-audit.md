## Provenance

The authoritative Linux stable interval contains 825 commits and no merge
commit. This branch imports 819 of those commits individually, retaining their
original authors, subjects, bodies, and dependency order. Six commits were
already represented by equivalent Android or local backports and were not
duplicated:

- the netfilter expectation-helper restoration series;
- three Logitech DJ HID fixes;
- the conditional vmscan flusher wakeup fix; and
- the F2FS merge-page-bio use-after-free fix.

The exact ordered inventory and the corresponding `ALREADY_PRESENT` evidence
are recorded in
`oos1610601-linux-6.12.101-to-6.12.107-commits.tsv`. The history includes each
completed point boundary from Linux 6.12.102 through 6.12.107. No stable
interval was squashed.

## Downstream compatibility repairs

Commit `54181b15c325` was made at the first affected stable commit and remains
separate from official Linux history. It assigns the new fsnotify permission
state to an unused bit while preserving the OOS-visible `FMODE_BACKING` and
`FMODE_NONOTIFY` values, and retains canonical lower-path notifications used
by Android stacked filesystems.

Commit `7d8077c960ca` is the final isolated KABI compatibility repair. It keeps
the stable runtime/security behavior while preserving the qualified OOS
16.0.10.601 provider representation for:

- netfs request state;
- `pcpu_dstats` and the type-aware tunnel-statistics update;
- SDHCI tuning errors;
- trace-event filter storage and bit numbering;
- UCSI lock-class storage;
- the legacy exported TCP ACK and inet-fragment APIs;
- `kmalloc_caches` type visibility;
- Qdisc depth storage;
- TCP bitfield placement; and
- complete fsnotify type visibility used by GENDWARFKSYMS.

The new in-tree fragment API remains exported as `inet_frag_kill_deferred`.
The legacy `inet_frag_kill` provider remains exported with its qualified CRC.
No CRC, `Module.symvers`, vermagic, stock module, or module version section was
modified.
